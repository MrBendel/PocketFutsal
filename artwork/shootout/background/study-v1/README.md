# Shootout background concepts

Built-in ImageGen created the indoor-arena concept using the current Shootout screenshot for camera/game context and the original spiky roster sheet for character identity. The goal is freestanding with a roof, receding side nets, a rear frame and visible ground contact. This is high-fidelity inspiration artwork, not a native 160×144 background.

`indoor-arena.png` is the first concept. Feedback: the goal looked too small. `indoor-arena-larger-goal.png` is the revised study, with a wider, slightly taller goal and the same court/venue composition. The original generated files are preserved without image processing.

`indoor-arena-taller-goal.png` responds to the next request for extra jump-animation headroom: the crossbar is raised again, retaining the revised width, centered placement and goal line. It is the latest concept for review. A native-size keeper high-dive overlay must still verify the final clearance before implementation.

Exact prompts are `indoor-arena-prompt.txt`, `indoor-arena-larger-goal-prompt.txt` and `indoor-arena-taller-goal-prompt.txt`. Neighbourhood and night-stadium prompt files are unexecuted ideas; those variants are deferred while the goal proportions are reviewed.

No gameplay, camera, target positions, tiles or hitboxes have changed. Before implementation, simplify the selected design to the handheld palette/tile budget and align the physical opening, keeper reach points and shot targets together. Characters/ball in these concepts are scale references rather than reusable background pixels.
